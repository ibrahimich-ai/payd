# Контракт данных Supabase

Проверь, что форма данных совпадает между кодом и Supabase.

## Что искать
- Поля, которые код пишет (`insert` / `update`), но которых может не быть в таблице, и наоборот
- Рассинхрон имён полей (camelCase в коде vs snake_case в БД)
- Чтение полей, которые нигде не заполняются
- Отсутствие проверки на null / пустой ответ перед использованием данных
- Несогласованные типы (строка vs число для сумм / id)

## Отчёт
Стык (файл + запрос), ожидаемая форма, фактическая, риск, как выровнять. В конце: чисто / список по приоритету. Только отчёт.
